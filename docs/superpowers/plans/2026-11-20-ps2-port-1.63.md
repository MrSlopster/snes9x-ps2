# Snes9x 1.63 → PS2 Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce `ps2/snes9x.elf` — a PS2 port of the upstream Snes9x 1.63 core with a new platform layer in `ps2/`, building cleanly in the Docker ps2dev toolchain.

**Architecture:** Upstream master is the base tree; all port code is new code under `ps2/`, calling the 1.63 core through its documented port hooks (unix port + libretro core as references). No core emulation logic is modified. Video blits `GFX.Screen` (RGB565) to the GS via ps2sdk `graph/draw/dma`; audio implements the modern `S9xSoundDriver` base class over `audsrv`; input feeds `S9xReportButton` from `libpad`.

**Tech Stack:** C/C++ (EE MIPS R5900), ps2sdk (modern, in `ghcr.io/ps2dev/ps2dev:latest`), zlib from ps2sdk-ports, ps2sdk Makefile.pref/eeglobal build system, Docker.

**Spec:** `docs/superpowers/specs/2026-11-20-ps2-port-1.63-design.md`

## Review Focus

Inputs/conditions no automated test here can exercise — every task that owns one must keep the path simple and fail-safe:

1. **ZIP/7z/JMA ROM loading** — zlib is linked, but a broken or misaligned gz stream read on PS2 I/O must degrade to "load failed" message, not a hang. (Owner: Task 5; check: snapshot stream code returns FALSE on NULL stream.)
2. **PAL vs NTSC pacing** — frame timing comes from `S9xSyncSpeed`/`Timings`; port must not hardcode NTSC assumptions in a way that freezes PAL. (Owner: Task 2/3; check: video waits on GS vsync only as a display sync, never as the sole frame timer.)
3. **Sound buffer underrun/overflow** — audsrv driver must never busy-spin; `audsrv_wait_audio` blocking is the safety valve. (Owner: Task 3; check: `write_samples` returns after queueing, ring math saturates.)
4. **Missing/absent files** — no ROM, no SRAM dir, unwritable MC → clean message path, emulation still boots when possible. (Owner: Task 5/6; check: `S9xOpenSnapshotFile` FALSE path exercised.)
5. **Multitap detection quirks** — if `libmtap` open fails, port must silently fall back to 2 pads. (Owner: Task 4; check: init code has no fatal path on mtap failure.)

- [ ] **Step 1: Write GS init + blit**

Model on `$PS2SDK/samples` (graphics/draw2d samples inside the image; list
them with `docker run --rm ghcr.io/ps2dev/ps2dev:latest ls $PS2SDK/samples`).
Implementation pattern (classic ps2sdk graphics stack, no gsKit):

```cpp
#include <dma.h>
#include <dma_tags.h>
#include <draw.h>
#include <graph.h>
#include <gs_psm.h>
#include <packet.h>
// ...
#define FB_WIDTH  640
#define FB_HEIGHT 448
static u32 vram_tex;   // texture address in VRAM
static u32 vram_fb;    // framebuffer 0
static u32 vram_fb2;
static packet_t *pkt;

void ps2_video_init(void)
{
	// 1. graph init, NTSC 640x448 non-interlaced
	graph_initialize();
	int mode = graph_get_region() == GRAPH_PAL ? GRAPH_MODE_PAL : GRAPH_MODE_NTSC;
	graph_set_mode(mode, GRAPH_MODE_NONINTERLACED, GRAPH_MODE_FIELD, GRAPH_ENABLE);
	// framebuffers: PSMCT32 640x448 double-buffered
	vram_fb  = 0;
	vram_fb2 = graph_vram_2d_allocation(0, GS_PSM_32);
	graph_set_framebuffer(0, vram_fb, FB_WIDTH, GS_PSM_32, 0);
	graph_set_framebuffer(1, vram_fb2, FB_WIDTH, GS_PSM_32, 0);
	graph_active(GRAPH_SETGRAPH_ENABLED);
	// texture block: 256x224 RGB565 up to 512x480
	vram_tex = graph_vram_2d_allocation(vram_fb2 + ..., GS_PSM_T16);
	// clear framebuffers, set zbuffer off or 32-bit z
	// 2. allocate 16M-ish packet, init draw environment:
	pkt = packet_init(0x4000, PACKET_NORMAL);
	qword_t *q = packet_header(pkt, &context, 0, 0);
	draw_context_init(&context, FB_WIDTH, FB_HEIGHT, ...);
	draw_enable_alpha_blend(0);
	draw_enable_blending(0);
}

void ps2_video_frame(const uint16 *src, int width, int height)
{
	// a) DMA src (RGB565, width aligned to 8/16) to vram_tex as GS_PSM_T16
	//    - Copy through a 16-byte-aligned staging area if src isn't aligned;
	//      GFX.Screen is 16-aligned (core mallocs + offsets by RealPPL*32,
	//      verify alignment at runtime; if not aligned, memcpy-staged blit).
	//    - texbuffer definition: width=512 (power of 2 req'd by GS), height=h
	// b) build one draw packet: textured sprite covering the framebuffer,
	//    UVs mapping source (0..w, 0..h) onto framebuffer (0..FB_WIDTH,0..FB_HEIGHT),
	//    tex0 register: PSM=GS_PSM_T16, filter linear, wrap clamp
	// c) packet_flip: wait vsync, swap framebuffer, flush cache before DMA
}
```

Blit sizing details the executor must implement:
- texture upload: `q = draw_texture_transfer(q, (u32)staging, width_aligned, height, GS_PSM_T16, vram_tex, texbuf_width);`
  `q = draw_texture_flush(q);` preceded by `SifWriteBackDCache(staging, size)` (or copy into a static aligned buffer when `((uintptr_t)src & 0xF)`).
- draw: `draw textured sprite` = two TRIS primitives with `SET_PRIM(MULTI_PASSTHROUGH)`… simplest correct form is `draw_sprite` via the draw2d API (`draw2d` helpers) — check the sample for exact calls; DO NOT hand-roll qwords unless the sample does.
- texbuf width must be a power of two ≥ texture width (512 for 512-wide frames; 256 for 256-wide).

```cpp
#include "s9x_sound_driver_audsrv.hpp"
#include <audsrv.h>
#include <string.h>

static audsrv_fmt_t fmt = { 48000, 16, 2 };

void S9xAudsrvSoundDriver::init()
{
	audsrv_init();
}

void S9xAudsrvSoundDriver::deinit()
{
	audsrv_stop_audio();
	audsrv_quit();
}

bool S9xAudsrvSoundDriver::open_device(int playback_rate, int buffer_size)
{
	(void)buffer_size; // audsrv owns its internal ring buffer
	fmt.freq = playback_rate;
	if (audsrv_set_format(&fmt) != AUDSRV_ERR_NOERROR)
		return false;
	return true;
}

void S9xAudsrvSoundDriver::start() { audsrv_set_volume(MAX_VOLUME); }
void S9xAudsrvSoundDriver::stop()  { audsrv_stop_audio(); }

bool S9xAudsrvSoundDriver::write_samples(int16_t *data, int samples)
{
	int bytes = samples * 2; // stereo int16 = 4 bytes/sample pair; see below
	// NOTE: 'samples' counts individual samples per channel? Check the OSS
	// driver: write_samples receives interleaved stereo samples count
	// (frames*2). Match OSS semantics exactly: bytes = samples * sizeof(int16_t).
	bytes = samples * sizeof(int16_t);
	audsrv_wait_audio(bytes);          // blocks when full: safety valve
	return audsrv_play_audio((const char *)data, bytes) >= 0;
}

int S9xAudsrvSoundDriver::space_free()
{
	// audsrv exposes remaining ring space via audsrv_get_absolute_volume-free
	// internal state; simplest correct v1: return a constant generous value so
	// the core throttle uses buffer_level only.
	return 32768;
}

std::pair<int, int> S9xAudsrvSoundDriver::buffer_level()
{
	// (level, max). Without a public audsrv API for queued bytes, v1 reports a
	// nominal mid-buffer level so S9xSyncSpeed throttles on frame count.
	return { 4096, 32768 };
}
```

```cpp
#include <pad.h>
#include <mtap.h>
#include <kernel.h>
#include "ps2_controls.h"
#include "controls.h"

#define MAKE_BUTTON(pad, btn) (((pad)<<4)|(btn))
#define PAD_1 1
#define PAD_2 2
// SNES button index map (see Global Constraints):
enum { SN_B=0, SN_Y=1, SN_SELECT=2, SN_START=3, SN_UP=4, SN_DOWN=5,
       SN_LEFT=6, SN_RIGHT=7, SN_A=8, SN_X=9, SN_L=10, SN_R=11 };

static int pad_buf1[640] __attribute__((aligned(64)));
static int pad_buf2[640] __attribute__((aligned(64)));
static bool mtap_ok = false;

void ps2_input_init(void)
{
	mtap_init();
	pad_init();
	// mtap: best-effort; failure falls back to 2 pads (Review Focus #5)
	if (mtap_port_open(0) == 1 && mtap_port_open(1) == 1)
		mtap_ok = true;
	pad_port_open(0, pad_buf1, PAD_MODE_1); // mode: digital pad
	pad_port_open(1, pad_buf2, PAD_MODE_1);
	S9xSetController(0, CTL_JOYPAD, 0, 0, 0, 0);
	S9xSetController(1, CTL_JOYPAD, 1, 0, 0, 0);
	S9xReportControllers();
}

void ps2_input_poll(void)
{
	static uint16 last[2] = { 0xffff, 0xffff };
	struct padState st;
	uint16 buttons[2];
	// padRead/GetState pattern: use padGetState(port) to wait STABLE,
	// then padRead(port, buf) -> struct padData; digital button mask field.
	// (Executor: match $PS2SDK/ee/include/pad.h + samples exactly;
	//  fall back: digital data via padRead into padData, use btn bitfield.)
	for (int p = 0; p < 2; p++)
	{
		if (padGetState(p) != PAD_STATE_STABLE) { /* keep last */ }
		else {
			struct padData *d = (struct padData *)padRead(p, p == 0 ? (char*)pad_buf1 : (char*)pad_buf2);
			buttons[p] = d->btn; // active-low in PS2 pad data
		}
		// Map: tri->Y(1), circle->A(8), cross->B(0), square->X(9),
		//      L1->L(10), R1->R(11), start->3, select->2,
		//      up/down/left/right -> 4/5/6/7
		uint16 b = ~buttons[p];
		bool v[12] = {
			(b & PAD_CROSS) != 0,   // 0 B
			(b & PAD_SQUARE) != 0,  // 1 Y
			(b & PAD_SELECT) != 0,  // 2 select
			(b & PAD_START) != 0,   // 3 start
			(b & PAD_UP) != 0,      // 4 up
			(b & PAD_DOWN) != 0,    // 5 down
			(b & PAD_LEFT) != 0,    // 6 left
			(b & PAD_RIGHT) != 0,   // 7 right
			(b & PAD_CIRCLE) != 0,  // 8 A
			(b & PAD_TRIANGLE) != 0,// 9 X
			(b & PAD_L1) != 0,      // 10 L
			(b & PAD_R1) != 0,      // 11 R
		};
		for (int i = 0; i < 12; i++)
			S9xReportButton(MAKE_BUTTON(p + 1, i), v[i]);
	}
}
```

(Executor note: the exact pad API in modern ps2sdk is `padPortOpen(int,
int, void*)`, `padRead(int, int, struct padData*)`, `padGetState(int)` —
verify against `$PS2SDK/ee/include/pad.h` inside the image and the
`$PS2SDK/samples/pad` sample; the sketch above names them approximately and
MUST be corrected during the build loop. Digital `padData.btn` is active-low.)

```cpp
const char *S9xGetDirectory(enum s9x_getdirtype t)
{
	static char dir[300];
	if (t == ROMFILENAME_DIR)
	{
		char *s = strrchr(Memory.ROMFilename, '/');
		if (s) { snprintf(dir, sizeof(dir), "%.*s", (int)(s - Memory.ROMFilename), Memory.ROMFilename); return dir; }
		return base;
	}
	if (subdir[t][0])
		snprintf(dir, sizeof(dir), "%s/%s", base, subdir[t]);
	else
		strcpy(dir, base);
	return dir;
}
```

```cpp
const char *S9xGetFilename(const char *ext, enum s9x_getdirtype t)
{
	static char fn[300];
	// basename of Memory.ROMFilename without extension
	const char *s = strrchr(Memory.ROMFilename, '/');
	char name[128];
	if (s) snprintf(name, sizeof(name), "%s", s + 1); else snprintf(name, sizeof(name), "%s", Memory.ROMFilename);
	char *dot = strrchr(name, '.'); if (dot) *dot = 0;
	snprintf(fn, sizeof(fn), "%s/%s%s", S9xGetDirectory(t), name, ext);
	return fn;
}

const char *S9xGetFilenameInc(const char *ext, enum s9x_getdirtype t)
{
	static char fn[300];
	char name[128]; // (same basename extraction as above — factor a static helper split_base())
	for (int i = 0; i < 1000; i++)
	{
		snprintf(fn, sizeof(fn), "%s/%s.%03d%s", S9xGetDirectory(t), name, i, ext);
		iox_stat_t st;
		if (fileXioGetStat(fn, &st) < 0) return fn; // free slot
	}
	return fn;
}

bool8 S9xOpenSnapshotFile(const char *filepath, bool8 read_only, STREAM *file)
{
	if (read_only)
		*file = OPEN_STREAM(filepath, "rb");   // gzread-aware stream
	else
		*file = OPEN_STREAM(filepath, "w9h");  // deflate best compression
	return *file != NULL;
}

void S9xCloseSnapshotFile(STREAM file) { CLOSE_STREAM(file); }
```
